Choose the browser where you loaded Bread Box. Only that browser will be enabled.

Download and run your installer. It already includes your browser choice and extension ID.

Requires Node.js 22 or newer on Linux or macOS. The companion keeps account sessions on this computer. No administrator access needed.

How do I run the installer?

On Linux, open the downloaded file’s Properties, allow it to run as a program, then choose Run in Terminal. File managers vary; some require opening shell scripts from a terminal. On macOS, downloaded scripts may also require execute permission before opening in Terminal. This version requires Node.js 22 or newer, available from nodejs.org.

After installation, return here and check the connection. You do not need the project folder to run this installer.
